# tui_live_kit

Tencent UIKit Live desktop plugin (macOS), based on AtomicXCore.

## Requirements

| Flutter | 状态 |
|---|---|
| >= 3.44 | 推荐。Swift Package Manager 默认开启，`flutter pub get` 后直接构建，零额外配置 |
| 3.38 ~ 3.43 | 可用。需先执行 `flutter config --enable-swift-package-manager` 开启 SwiftPM |
| < 3.38 | `pub get` 时被 SDK 约束拦截 |
